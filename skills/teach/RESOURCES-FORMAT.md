# RESOURCES.md Format

```markdown
# Resources

## Primary Sources

| Resource     | Type                         | Trust         | Why it's here |
| ------------ | ---------------------------- | ------------- | ------------- |
| [Title](url) | book / video / course / docs | high / medium | <one line>    |

## Communities

| Community   | Where                           | Why it's here |
| ----------- | ------------------------------- | ------------- |
| [Name](url) | forum / subreddit / local group | <one line>    |

## Explored But Rejected

- [Title](url) — <why it was rejected>
```

Rules:

- Only add resources you have actually inspected — never from parametric memory alone.
- Record trust level honestly; prefer primary sources, recognized experts, and peer-reviewed or widely-vetted material.
- Keep the rejected list: it prevents re-evaluating the same weak resources across sessions.

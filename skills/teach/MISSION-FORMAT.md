# MISSION.md Format

```markdown
# Mission

## Topic

<what the user is learning, in one line>

## Why

<the real-world reason the user wants to learn this, in their own words>

## Success Looks Like

<concrete, observable outcomes that would mean the mission is accomplished>

## Constraints

<time available, budget, equipment, prior commitments — anything that shapes lesson design>

## Current Level

<honest snapshot of where the user is starting from>

## History

- YYYY-MM-DD: <mission created / revised, and why>
```

Keep it short. Every section should be readable in under a minute. Update the History section whenever the mission changes, and add a learning record capturing the change.

# Learning Record Format

Files are named `NNNN-<dash-case-title>.md` in `./learning-records/`, where `NNNN` increments each time (`0001-...`, `0002-...`).

```markdown
# NNNN. <Title>

Date: YYYY-MM-DD
Lesson: <link to the lesson this came from, if any>

## What Was Learned

<the skill or knowledge acquired, stated plainly>

## Evidence

<how the user demonstrated it — quiz score, completed task, real-world attempt>

## Key Insight

<the non-obvious thing worth remembering — the part a future session must not re-teach or contradict>

## Struggles

<what was hard, what to revisit, misconceptions surfaced>

## Next

<what this unlocks — candidate topics now inside the zone of proximal development>
```

One record per meaningful learning event, not per session. Records are append-only; if an insight later proves wrong, write a new record that supersedes it and link back to the old one.
